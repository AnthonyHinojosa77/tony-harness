# tony-harness

My very own AI agent harness for managing agent workflows, evaluation, and tool orchestration.

## Quick Start

```bash
# Clone and install dependencies
git clone https://github.com/AnthonyHinojosa77/tony-harness.git
cd tony-harness
pnpm install

# Start the local development server
pnpm dev
```

## Architecture at a Glance

- **Client:** Web / terminal interface for interacting with agent runs
- **API / Engine:** Agent orchestration core, tool execution, and session management
- **Contracts / Shared:** Shared TypeScript types, schemas, and event contracts
